# ControlTime

Родительский контроль для Windows 11 x64. Установщик содержит приложение, службу и среду выполнения .NET. На ноутбуке достаточно запустить `ControlTime-Setup-x64.exe` с правами администратора.

## Настройка

1. В параметрах Windows создайте для ребёнка отдельную локальную учётную запись типа «Обычный пользователь». У родителя должна быть собственная учётная запись администратора с паролем.
2. Запустите установщик. В меню «Пуск» откройте **ControlTime**, укажите имя локальной учётной записи ребёнка и выберите часовой пояс расписания. Сохраните настройки.
3. Для схемы «час занятия, три часа перерыва, ещё час занятия» оставьте две строки **60 / 180** и **60 / 0**. Последнее занятие закрывает доступ до следующего дня. Расписание повторяется каждый день, а новый дневной лимит начинается в полночь по выбранному часовому поясу.
4. Чтобы закрыть доступ с 20:00 до 10:00 ежедневно, добавьте строку **20:00 / 10:00** для каждого из семи дней. День в строке означает день начала запрета. Например, запрет понедельника действует до 10:00 вторника.
5. После запуска Windows выберите учётную запись ребёнка. Ограничения применяются автоматически. Чтобы работать без ограничений, на экране входа Windows выберите учётную запись родителя и введите её пароль. Перед передачей ноутбука ребёнку завершите работу в учётной записи родителя или заблокируйте её.

Служба списывает время, пока сеанс ребёнка активен. Перерыв отсчитывается по обычным часам, включая время работы родителя и время, когда ноутбук выключен. После двух часов работы родителя из трёхчасового перерыва остаётся один час. Израсходованное время записывается на диск до предоставления каждой секунды. При истечении лимита или начале запретного интервала ноутбук выключается, если других пользователей в системе нет. Если родитель оставил открытый сеанс, служба завершает сеанс ребёнка и сохраняет сеанс родителя. Принудительное завершение сеанса может привести к потере несохранённых данных ребёнка.

У Windows остаётся обычный экран входа. Пароль родителя проверяет Windows. Настройки, счётчик, исполняемые файлы и остановка службы защищены правами администратора. Служба действует только для указанной учётной записи. Для защиты при физическом доступе к ноутбуку нужны шифрование диска, ограничения загрузки с внешних носителей и защита настроек UEFI. Обычная служба Windows не обеспечивает контроль при загрузке в безопасном режиме.

## Сборка

Требуются SDK .NET 10 и NSIS 3. Из корня репозитория выполните:

```powershell
dotnet run -c Release --project tests/PolicyChecks.csproj
dotnet publish src/Windows/Windows.csproj -c Release -r win-x64 --self-contained true -o artifacts/windows
makensis installer/ControlTime.nsi
```

Установщик появится в `artifacts/ControlTime-Setup-x64.exe`. Для распространения подпишите его доверенным сертификатом подписи кода.

## Проверка на Windows

Проверяйте на тестовом ноутбуке или в виртуальной машине. Для ускорения задайте два занятия по минуте с трёхминутным перерывом. Проверьте выключение, повторный вход после перезагрузки, вход под родителем во время перерыва, доступ после окончания перерыва и запрет для интервала через полночь. Из детской учётной записи проверьте, что Windows запрашивает данные администратора для открытия настроек и удаления программы, а файлы и служба недоступны для изменения.
