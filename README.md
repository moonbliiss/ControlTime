# ControlTime

[Скачать установщик ControlTime для Windows 11 x64](https://github.com/moonbliiss/ControlTime/raw/refs/heads/downloads/ControlTime-Setup-x64.exe)

Родительский контроль в одной учётной записи Windows. Установщик содержит приложение, службу и среду выполнения .NET.

## Настройка и работа

1. Запустите `ControlTime-Setup-x64.exe` с правами администратора. В конце установки задайте отдельный пароль ControlTime длиной от 12 символов. Для обновления с предыдущей версии установите новый пароль. Расписание и израсходованное время сохранятся.
2. Откройте **ControlTime → Расписание**. Для схемы «час занятия, три часа перерыва, ещё час занятия» оставьте две строки **60 / 180** и **60 / 0**. Укажите часовой пояс и подтвердите сохранение паролем ControlTime. После последнего занятия детский доступ закрывается до следующего дня. Дневной лимит начинается заново в полночь по выбранному часовому поясу.
3. Чтобы закрыть доступ с 20:00 до 10:00 ежедневно, добавьте строку **20:00 / 10:00** для каждого из семи дней. День в строке означает день начала запрета. Например, запрет понедельника действует до 10:00 вторника.
4. После входа в Windows включён детский режим. Чтобы работать без временных ограничений, откройте ControlTime, введите пароль и нажмите **Включить родительский режим**. Выйдите через **Вернуться в детский режим**, прежде чем передавать ноутбук ребёнку. После выхода из сеанса Windows или перезагрузки снова включается детский режим.

Служба списывает время, пока сеанс открыт, разблокирован и работает в детском режиме. Перерыв отсчитывается по обычным часам, включая работу родителя и время, когда ноутбук выключен. После двух часов работы родителя из трёхчасового перерыва остаётся один час.

При истечении лимита или начале запретного интервала ноутбук выключается. Принудительное выключение может привести к потере несохранённых данных. Если попытаться войти снова во время запрета, счётчик останется прежним. ControlTime откроет полноэкранный запрос пароля и даст до 30 секунд на вход родителя перед повторным выключением. Эту паузу можно снова получить после перезагрузки, поэтому она оставляет короткое окно работы с рабочим столом.

Пароль проверяет системная служба. Она хранит производный хеш с индивидуальной солью в каталоге, доступном Windows-администраторам и системе, и увеличивает задержку после неверных попыток. Права администратора Windows по-прежнему позволяют отключить службу или удалить ControlTime. Полноэкранное окно находится в общем сеансе, поэтому оно не обеспечивает изоляцию от процессов, которые уже запущены в этой учётной записи. Служба работает при обычной загрузке Windows. Первоначальная настройка и восстановление забытого пароля требуют административных прав Windows.

## Сборка

Требуются SDK .NET 10 и NSIS 3. Из корня репозитория выполните:

```powershell
dotnet run -c Release --project tests/PolicyChecks.csproj
dotnet publish src/Windows/Windows.csproj -c Release -r win-x64 --self-contained true -o artifacts/windows
makensis /INPUTCHARSET UTF8 installer/ControlTime.nsi
```

Установщик появится в `artifacts/ControlTime-Setup-x64.exe`. Для распространения подпишите его доверенным сертификатом подписи кода.

## Проверка на Windows

В тестовой Windows установите ControlTime, создайте пароль и задайте два занятия по минуте с трёхминутным перерывом. Дождитесь выключения и войдите в ту же учётную запись. Проверьте, что лимит сохранился, неверный пароль отклоняется, а верный включает родительский режим. Оставьте его на две минуты, затем вернитесь в детский режим и проверьте оставшуюся минуту перерыва. Проверьте запрет через полночь, перезагрузку в родительском режиме и запрос пароля при сохранении расписания. Для проверки обновления установите новую версию поверх старой с частично израсходованным лимитом.
